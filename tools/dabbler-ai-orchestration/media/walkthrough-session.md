# Start session 1

Session 1 authors the project plan. Session 2 breaks it into numbered
sessions.

Session 1 waits on one thing: what the project is. The plan's substance is
yours — its purpose, what success looks like, the phases you have in mind —
and the engine asks for it rather than guessing it from the folder. Have a
brief, a ticket or notes ready if they exist; it imports them.

From then on the Work Explorer shows what is running, which step it is on,
and anything waiting on you.
