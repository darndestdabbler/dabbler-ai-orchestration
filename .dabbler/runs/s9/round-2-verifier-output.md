**ISSUES FOUND** — The two round-1 blockers are addressed in the opened hunks: freshness now reads per-provider timestamps, and the API record is no longer packaged from `ai_router/`. But the new default path introduces a blocking first-run failure on the main `enumerate` path.

- **Issue 1:** The shipped `.dabbler/api-models.lock` default cannot be created on first use.
  - **Category:** Correctness
  - **Severity:** Major
  - **Evidence paths:** `ai_router/discovery.py:73,988-1001`, `ai_router/lockfile.py:111-114`, `ai_router/router-config.yaml:112-119`
  - **Failure scenario:** On a normal first run of `python -m ai_router.discovery enumerate`, the record path resolves to `<project>/.dabbler/api-models.lock`. `cmd_enumerate()` writes that path directly, but the sanctioned writer never creates parent directories. On any fresh checkout or install where `.dabbler/` does not already exist—the common first-use case for this command—the write raises `FileNotFoundError`, so enumeration produces no record at all.
  - **Acceptance criterion:** `python -c "import importlib, pathlib, sys, tempfile, types; root=pathlib.Path('.').resolve(); pkg=types.ModuleType('ai_router'); pkg.__path__=[str(root/'ai_router')]; pkg.__version__='1.1.0'; sys.modules['ai_router']=pkg; discovery=importlib.import_module('ai_router.discovery'); tmp=pathlib.Path(tempfile.mkdtemp()); discovery.write_record(tmp/'.dabbler'/'api-models.lock', discovery.empty_record())"`
  - **Acceptance expectation:** `exit 0`
  - **Details:** **Violation** — `"Enumerate each vendor's models endpoint on the direct-API path and write the record through the sanctioned writer, dated."` The shipped config now also says the record lives at `.dabbler/api-models.lock`. **Impact** — this is merge-blocking because the documented default path for the new feature fails on first use, so a typical operator cannot actually generate the discovery record. **Evidence** — `ai_router/discovery.py` changes the default to `.dabbler/api-models.lock` and `cmd_enumerate()` calls `write_record(path, merged)` directly; `ai_router/lockfile.py` implements that writer as a bare `Path(path).write_text(...)`, which does not create the new parent directory. The fix is to create the parent directory on the write path before writing the record.
