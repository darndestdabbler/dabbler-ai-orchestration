# Sam's notes sheet

Copy this, fill it in **as you go**, and send it to Priya. Two hours compresses badly in
memory — a note written five minutes later is worth more than five written at the end.

**There is no pass/fail here on purpose.** You are not grading anything; you are reporting
what happened. Priya turns this into the formal record.

Label each note with **where you were in the tutorial** — "Part 5, adding the prerequisites
block" is perfect. You never need to know the walk numbers.

---

## How to write one

Four lines. If you only have the energy for two, write the last two.

```
Where:     Part 5, step 6 — running the decomposition set
What I did: pasted the starter line into copilot and pressed enter
Expected:   a new session set to appear under App
Saw:        nothing for about 4 minutes, then it appeared. Thought it had hung.
```

That last one is a real finding even though nothing broke. **"It worked but I thought it was
broken" is exactly the thing we cannot discover any other way.**

---

## Also worth a note, even when nothing goes wrong

- A sentence you had to read twice.
- A button or menu item that was not where the tutorial said it would be, or was named
  something slightly different.
- A moment you were not sure whether it was your turn or Priya's.
- A step where you guessed. **Especially** if the guess turned out right — a step that only
  works if you guess correctly is broken for the next person.
- Anything you had to ask Priya about. Every question you ask is a sentence the document
  should have contained.

## At the end, two questions

**1. If you had been handed only the tutorial, with nobody to ask — where would you have
stopped?**

> 

**2. Anything that annoyed you, that you would not report as a bug?**

> 

The second one matters. Friction that is not quite a defect is what makes people abandon a
tutorial halfway, and it is invisible to everyone except the person who felt it.
