Session 273 of 278: A cancelled session gets its transcript, marked cancelled

Scope: packages/router/src/session.ts (cancel, the rollback), packages/router/src/transcript.ts (the cancelled page), packages/router/src/drive.ts (phaseLog, when a restored session closes); tests in session.test.ts and transcript.test.ts

Why. The same developer: a cancelled session often had problems worth troubleshooting, sometimes in Dabbler itself, and cancelling leaves no record anyone else can read. The transcript is written only by the Log phase after a close; cancel marks the session cancelled, commits that, and stops. .dabbler/runs/ is untracked and per-machine, so the page is the only record a second developer or a maintainer of this repository can see. A packaging failure makes it worse: the publish stop tells the person to cancel the release session, so the failure that most needs reading is the one that leaves nothing behind. dabbler transcript --from N already renders a cancelled session by hand, and nothing on the page says it was cancelled.

Step 1 -- cancel writes the page. After the cancelled state is committed, cancel renders the session's transcript under the same dabbler.transcript setting the Log phase reads, commits it and pushes it. A page that fails to render, commit or push is said, and the cancel stands: the record is already written, and the page is never a reason to refuse it.

Step 2 -- the page says cancelled. A cancelled session's page opens with a CANCELLED banner, the reason given, when, and the last phase the run reached, and the rest of the page is what it carries today, failed job output included. A session cancelled before anything ran gets the short page that says so -- one rule, no exception for an empty one.

Step 3 -- the page outlives what follows. A rollback to the start of a cancelled session keeps its page. A cancelled session that is restored and later closes renders its closed page over the cancelled one -- the one case a page is replaced, because the session has left the state it describes.

Non-goals. Any change to who may cancel. Any change to what cancel unwinds, which is nothing. A transcript for a session that was never started.

Tests. In session.test.ts, a cancel commits a page that says cancelled; a rollback after it keeps the page. In transcript.test.ts, the cancelled banner carries the reason and the last phase.

Releasable. Yes -- with 272 to 277, as 3.23.0 in session 278.
