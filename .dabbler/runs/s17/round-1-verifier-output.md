ISSUES FOUND

- **Issue 1:** Multi-suite test ownership is discarded, so affected-test execution cannot reliably route tests to the suite that owns them.
  - **Category:** Correctness
  - **Severity:** Major
  - **Evidence paths:** `ai_router/checks.py, ai_router/affected.py, tests/test_affected.py`
  - **Failure scenario:** In the Java/.NET repository explicitly anticipated by the session, a shared source change selects both Java and .NET tests. `names_a_test` collapses all suite scopes to one boolean, while `SelectedTest` and `SelectionResult` retain no suite identity. Downstream targeted preverification therefore receives an undifferentiated path set and cannot ensure Maven gets only Java tests and `dotnet test` gets only .NET tests. Multi-ecosystem repositories are the stated next-session main path, and shared changes affecting both ecosystems are routine rather than exceptional.
  - **Acceptance criterion:** JUDGMENT - A two-suite Java/.NET configuration must preserve suite ownership through selection and targeted preverification, with each suite receiving only paths matching its own `test_roots` and `test_glob`, including when one changed path selects tests from both suites.
  - **Details:** **Violation:** The plan requires “**Suites become plural in fact, not only in the schema**” because a Java/.NET repository has two test roots and globs. **Impact:** The implementation cannot correctly construct suite-specific targeted runs for precisely that repository shape, materially defeating the session’s prerequisite for Session 18 and warranting blocking merge. **Evidence:** `SuiteScope` records a suite name, but `names_a_test` returns only `True` or `False`; `SelectedTest` contains only path, reason, and selector; and `SelectionResult.test_paths` is a global union. `ai_router.affected` re-exports this selector without adding suite partitioning. The new tests verify only that both ecosystems’ paths are globally recognized, not that selection or preverification routes them to their respective suite. The correct implementation must retain or derive suite identity for every selected target and partition targeted execution accordingly.
