**Issue 1:** The approved build sequence misses the §1.a default-transport deliverable.
- **Category:** Completeness
- **Severity:** Major
- **Evidence paths:** `docs/session-framework-spec.md:39-52`, `ai_router/router-config.yaml:56-61`, `ai_router/config.py:325-352`, `pyproject.toml:33-36`, `docs/session-sets/148-the-session-framework/spec.md:139-450`
- **Failure scenario:** A staff/fresh install follows the completed framework and still gets the packaged `api` transport default because the shipped `router-config.yaml` is package data and `resolve_transport()` falls through to that value/default. That is probable because no session in the approved sequence assigns changing the shipped config/staff default, while the current packaged config explicitly says `profile: api`.
- **Acceptance criterion:** `JUDGMENT - The approved build sequence names the session and step that makes Copilot CLI the default in the shipped configuration, staff-facing documentation, and extension/onboarding surfaces, or explicitly proves those surfaces already satisfy §1.a.`
- **Details:** **Violation:** §1.a says “The Copilot CLI seat is the default” and the table places it in “The extension, the staff documentation, the shipped configuration”; it also says direct API is “not the default anywhere.” **Impact:** Session 2’s claimed “nothing in the spec is unbuilt” approval would ship the wrong default path, sending typical staff toward API-key setup instead of the seat-first workflow the spec requires. **Evidence:** `router-config.yaml` still ships `transport.profile: api`, `config.py` returns `transport.profile`/`api` when no override is set, and the session list has transport-selection work but no default-transport migration. **Correct answer:** assign that default migration to a concrete session.

- **Severity:** Major
- **Evidence paths:** `docs/session-framework-spec.md:400-425`, `docs/session-sets/148-the-session-framework/spec.md:90-99`, `docs/session-sets/148-the-session-framework/spec.md:305-319`, `ai_router/verify.py:1365-1592`, `ai_router/verdict.py:23-32`, `ai_router/gates.py:116-123`
