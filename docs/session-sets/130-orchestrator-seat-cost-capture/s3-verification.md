- **Issue 1:** `close_session` renders `disposition.cost` without validating the cost contract first.
  - **Category:** Correctness
  - **Severity:** Major
  - **Evidence paths:** `ai_router/close_session.py:1422`, `ai_router/close_session.py:1477`, `ai_router/seat_cost.py:941`, `ai_router/disposition.py:450`
  - **Failure scenario:** A typical close-out records or hand-edits a malformed `disposition.cost` block with `status: "unknown"` but `credits: 0.0` / `usd: 0.0`—the exact fail-open shape this session is meant to prevent. Because `close_session` only checks `isinstance(block, dict)` and then renders it, the Step 10 close output can still print `$0.00` for an unmeasured component. This is probable enough to block because `disposition.cost` is a new manually carried JSON contract and the validator added for it is not wired into the report surface.
  - **Acceptance criterion:** `python -c "import io,sys; sys.path.insert(0,'ai_router'); import close_session; o=close_session.CloseoutOutcome(result='succeeded',session_set_dir='x',cost={'measured_at':'close','components':[{'component':'routed_seat','status':'unknown','credits':0.0,'usd':0.0}],'total_status':'unknown','total_credits':0.0,'total_usd':0.0,'unmeasured':['routed_seat']}); b=io.StringIO(); old=sys.stdout; sys.stdout=b; close_session._emit_output(o,json_mode=False); sys.stdout=old; raise SystemExit(1 if '$0.00' in b.getvalue() else 0)"`
  - **Acceptance expectation:** exit 0
  - **Details:** **Violation:** the session contract says an unmeasured component carries `credits: null` and a report containing one “never presents an unmeasured component as `$0.00`.” **Impact:** the primary user-facing close report can still emit the plausible wrong number this set exists to eliminate, so a reviewer should not merge until the report validates or refuses/safely renders invalid cost blocks. **Evidence:** `_apply_cost_report` accepts any non-empty dict as `outcome.cost`, `_emit_output` passes it directly to `format_cost_block`, and `format_cost_block` formats any non-`None` credits/usd as a dollar amount regardless of status; `_validate_cost` has the right rule but is not called on this path.
