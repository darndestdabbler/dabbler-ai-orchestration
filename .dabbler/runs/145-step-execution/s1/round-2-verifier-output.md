**ISSUES FOUND**

- **Issue 1:** Settled paths are blindly ignored, so a later step can modify an earlier step’s file outside its own envelope and still close.
  - **Category:** Correctness
  - **Severity:** Major
  - **Evidence paths:** `ai_router/approved_plan.py:521`, `ai_router/approved_plan.py:528`, `ai_router/ledger.py:255`, `ai_router/verify.py:1893`, `ai_router/affected.py:362`, `docs/quick-start.md:122`
  - **Failure scenario:** A normal multi-step plan closes step A for `a.py`, then opens step B for `b.py`. While doing B, the author also tweaks `a.py` again. Because `a.py` is in `settled_step_paths`, `compare_to_envelope` skips it instead of reporting it outside B’s envelope, and B closes with only `b.py` in `comparison.inside`. This is probable in real multi-step work because later integration steps commonly require follow-up edits to files created or changed by earlier steps, and the new no-commit-between-steps flow makes those files present in every later step.
  - **Acceptance criterion:** `JUDGMENT - A later step that modifies a path closed by an earlier step but not declared in its own file_envelope is refused as outside-envelope, while an unchanged settled path from the earlier step is still ignored so the next disjoint step can close.`
  - **Details:** Violation: the session contract says, “A write outside the step’s declared paths is refused at the boundary,” and the docs say “A path outside is refused.” Impact: the core mechanical envelope guarantee fails open; an undeclared edit bypasses amendment review and deterministic selection because the path is omitted from `comparison.inside`. Evidence: `run_step_close` passes all previously closed inside paths as `settled`, `compare_to_envelope` skips any changed path whose normalized path is in that set, and `working_tree_changes` only reports the cumulative diff against the original baseline tree, so the implementation cannot distinguish “unchanged work from step A” from “step B edited step A’s file again.” The fix needs a per-close tree/content baseline or equivalent so only unchanged settled paths are dropped.
